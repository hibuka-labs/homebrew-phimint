# homebrew-phimint

The Homebrew tap for [phimint](https://github.com/hibuka-labs/phimint) — a terminal AI coding agent built on phi-agent.

```bash
brew install hibuka-labs/phimint/phimint
```

`Formula/phimint.rb` is synced from the main phimint repository at every release
(by `deploy/release.sh`). Do not hand-edit it.
